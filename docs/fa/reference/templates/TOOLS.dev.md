# TOOLS.md - یادداشت‌های ابزار کاربر (قابل ویرایش)

این فایل برای یادداشت‌های _شما_ درباره ابزارها و قراردادهای بیرونی است. این فایل تعیین نمی‌کند چه ابزارهایی وجود دارند؛ OpenClaw ابزارهای داخلی را فراهم می‌کند و Skills بقیه را اضافه می‌کنند.

## نمونه‌ها

### imsg

- ارسال iMessage/SMS: مخاطب و محتوا را مشخص کنید و پیش از ارسال تأیید بگیرید.
- پیام‌های کوتاه را ترجیح دهید؛ از ارسال اطلاعات محرمانه خودداری کنید.

### sag

- تبدیل متن به گفتار: صدا، بلندگو/اتاق مقصد و پخش جریانی یا غیرجریانی را مشخص کنید.

هر نکته دیگری را که می‌خواهید دستیار درباره زنجیره‌ابزار محلی شما بداند، اضافه کنید.
