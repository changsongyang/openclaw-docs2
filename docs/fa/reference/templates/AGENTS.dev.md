# AGENTS.md - فضای کاری OpenClaw

این پوشه دایرکتوری کاری دستیار است که با `openclaw gateway --dev` مقداردهی اولیه شده است.

## هویت شما از پیش مقداردهی شده است

برخلاف یک فضای کاری تازهٔ `openclaw onboard`، این فضای کاری `--dev` آیین تعاملی
BOOTSTRAP.md را رد می‌کند و با هویتی از پیش تکمیل‌شده آغاز می‌شود:

- هویت عامل شما در IDENTITY.md قرار دارد.
- پروفایل کاربر در USER.md قرار دارد.
- شخصیت شما در SOUL.md قرار دارد.

اگر هویت توسعه‌دهندگی متفاوتی می‌خواهید، هرکدام از این فایل‌ها را مستقیماً ویرایش کنید.
