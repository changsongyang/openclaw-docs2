# TOOLS.md - उपयोगकर्ता टूल नोट्स (संपादन योग्य)

यह फ़ाइल बाहरी टूल और परंपराओं के बारे में _आपके_ नोट्स के लिए है। यह निर्धारित नहीं करती कि कौन-से टूल उपलब्ध हैं; OpenClaw आंतरिक रूप से अंतर्निहित टूल प्रदान करता है, और Skills शेष टूल जोड़ते हैं।

## उदाहरण

### imsg

- iMessage/SMS भेजें: किसे/क्या भेजना है, इसका वर्णन करें और भेजने से पहले पुष्टि करें।
- छोटे संदेशों को प्राथमिकता दें; सीक्रेट भेजने से बचें।

### sag

- टेक्स्ट-टू-स्पीच: आवाज़, लक्षित स्पीकर/कमरा और स्ट्रीम करना है या नहीं, यह निर्दिष्ट करें।
