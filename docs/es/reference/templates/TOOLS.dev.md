# TOOLS.md - Notas de herramientas del usuario (editable)

Este archivo es para _tus_ notas sobre herramientas externas y convenciones. No define qué herramientas existen; OpenClaw proporciona internamente herramientas integradas y las Skills añaden el resto.

## Ejemplos

### imsg

- Enviar un iMessage/SMS: describir a quién y qué se enviará; confirmar antes de enviarlo.
- Preferir mensajes breves; evitar enviar secretos.

### sag

- Texto a voz: especificar la voz, el altavoz o la sala de destino y si se transmitirá en tiempo real.

Añade cualquier otra información que quieras que el asistente conozca sobre tu cadena de herramientas local.
